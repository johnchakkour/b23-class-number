# The class number of $B_{23,1}$ is 1

[![verify](https://github.com/johnchakkour/b23-class-number/actions/workflows/verify.yml/badge.svg)](https://github.com/johnchakkour/b23-class-number/actions/workflows/verify.yml)

This repository contains an unconditional proof (not assuming the Generalized Riemann Hypothesis) that the number field $B_{23,1}$ has class number 1.

$B_{23,1}$ is the first layer of the cyclotomic $`\mathbb{Z}_{23}`$-extension of $\mathbb{Q}$: the unique subfield of degree 23 of $\mathbb{Q}(\zeta_{529})$, where $529 = 23^2$. That its class number is 1 was previously known under GRH; Table 1 of Miller [2] attributes this to Coates, Liang and Mihăilescu (2012).

The proof consists of a **certificate**, [`certificate/b23.certificate.txt`](certificate/b23.certificate.txt), and a **verifier**, [`verify/verify_certificate.py`](verify/verify_certificate.py), which checks the certificate and completes the argument below. The verifier uses only exact integer arithmetic and interval arithmetic.

The C code in this repository was written with the help of Claude Opus 5.5.


## The argument

Let $K = B_{23,1}$ and $h$ the class number of $K$. $K$ is totally real and cyclic of degree 23 over $\mathbb{Q}$, with discriminant $23^{44}$.

**Step 1: principal prime ideals.** A prime $q$ splits completely in $K$ exactly when $q^{22} \equiv 1 \pmod{529}$. Note that every other prime except 23 is inert. Take a split prime $q$. If an algebraic integer $\alpha \in K$ has $N(\alpha) = \pm q$, then $(\alpha)$ is a prime ideal above $q$, so that ideal is principal. Since $K/\mathbb{Q}$ is Galois, every prime ideal above $q$ is principal.

More generally, it is enough that $N(\alpha)$ is $\pm q$ times primes whose prime ideals are already known to be principal:

- 23, whose unique prime ideal is generated by $\prod_{k=0}^{21}\bigl(1 - \zeta^{5^{23k}}\bigr)$;
- inert primes $\ell$, for which $(\ell)$ is itself prime;
- split primes certified elsewhere in the certificate.

**Step 2: an upper bound.** Lemma 3.1 of Miller [1] turns a set $S$ of such primes into a bound on $h$. Let $c > 0$, $F(x) = e^{-(x/c)^2}/\cosh(x/2)$, and

```math
B = \frac{\pi}{2} + \gamma + \log 8\pi - \log \mathrm{rd}_K
  - \int_0^\infty \frac{1 - F(x)}{2}\left(\frac{1}{\sinh(x/2)} + \frac{1}{\cosh(x/2)}\right)dx
  + 2\sum_{q \in S}\sum_{m \ge 1} \frac{\log q}{q^{m/2}}\, F(m \log q),
```

where $\mathrm{rd}_K = 23^{44/23}$ is the root discriminant. If $B > 0$, then $h < 2c\sqrt{\pi}/(23B)$. With the 99,222 primes of the certificate and $c = 50$, this gives $h < 37.72$.

**Step 3: the possible values of $h$.** 23 does not divide $h$ (Iwasawa [3]). If a prime $\ell \ne 23$ divides $h$, then so does $\ell^f$, where $f$ is the order of $\ell$ modulo 23 (Masley's Rank Theorem [4]). The smallest such $\ell^f$ is $47$. So $h > 1$ would force $h \ge 47$, which contradicts $h < 37.72$. Hence $h = 1$.

## The certificate

Elements are written in the basis

```math
b_0 = 1, \qquad b_j = \sum_{h \in H} \zeta^{5^{j-1} h} \quad (1 \le j \le 22),
```

where $\zeta = e^{2\pi i/529}$ and $H$ is the subgroup of order 22 of $(\mathbb{Z}/529)^\times$. Each row certifies one prime. For example, this row (shown on three lines here, one line in the file):

```
263 Q N=79918745009447 support=[1,2,3,5,8,9,10,13] signs=[+1,-1,-1,-1,+1,-1,+1,+1]
      factors=23*23*263*574430161
      divide_out=574430161
```

states that $\alpha = b_1 - b_2 - b_3 - b_5 + b_8 - b_9 + b_{10} + b_{13}$ has norm $23^2 \cdot 263 \cdot 574430161$, where 574430161 is certified in its own row. So a prime ideal above 263 is principal.

Rows of kind `P` have norm $\pm q$; rows of kind `Q` use the other factors as in Step 1. The certificate contains the 99,167 split primes below $5 \cdot 10^7$ that the search certified, and 55 larger primes on which their rows depend.

For each row, the verifier computes the norm exactly, as the determinant of the integer matrix of multiplication by $\alpha$. It then checks:

- that every factor is prime and splits or is inert as required;
- that $q$ occurs exactly once;
- that every dependency is certified, with no circular chains.

Before checking any rows, it checks that the discriminant of the basis is exactly $23^{44}$.

## Reproducing the certificate

The certificate was produced in two steps; the code is in [`search/`](search/).

1. **Search** ([`bp1_norm_search.c`](search/bp1_norm_search.c), C with GMP, OpenMP and optionally MPI). It enumerates all $(3^{23}-1)/2 = 47{,}071{,}589{,}413$ elements $\pm\sum a_j b_j$ with coefficients $a_j \in \{-1, 0, 1\}$, and computes norms exactly by modular arithmetic. It records every element whose norm is a prime, or a product of primes below 65,536 and at most one larger prime, up to $10^{15}$. For each number of nonzero coefficients, the program checks that it covered exactly the expected number of elements (`COVERAGE_OK`).
2. **Certify** ([`certify_b23.py`](search/certify_b23.py), Python standard library only). It applies Step 1 to the search output, repeatedly, and writes the certificate. When several elements could certify the same prime, it takes the one with the fewest nonzero coefficients, ties broken by a fixed order. So the certificate depends only on the search results, not on how the search was run.

On the Trillium cluster (Digital Research Alliance of Canada), from the repository root:

```bash
jid=$(sbatch --parsable search/search_b23.slurm)
sbatch --dependency=afterok:$jid search/certify_b23.slurm
```

The search took 45 seconds on 10 nodes of 192 cores, about 25 core-hours in total. Certification took 8 minutes on one core. The output is in [`logs/`](logs/). On any other machine:

```bash
gcc -DNOMPI -O3 -march=native -fopenmp -o bp1_norm_search search/bp1_norm_search.c -lgmp -lm
./bp1_norm_search --p 23 --coeff 1 --bound 1000000000000000 --comp-bound 1000000000000000 --out run/b23
python3 search/certify_b23.py run/b23 --cutoff 50000000 --out b23.certificate.txt
```

(Create the folder `run/` first. The search writes about 4 GB of hits there.)

Either way, the result is identical to the certificate in this repository:

```
SHA-256  aef5bb15e4cbb889d75ddec27b7f58cf0fce73c89eb7410e0a07fa19dc18f181
```

Both programs have self-tests (`./bp1_norm_search --selftest 13`, `python3 search/certify_b23.py --selftest`). GitHub Actions runs them on every push, together with the verifier and a small end-to-end run of the whole pipeline.
